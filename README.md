# Расписание путешествий

iOS-приложение для поиска поездов между станциями. Данные приходят из API [«Яндекс Расписаний»](https://yandex.ru/dev/rasp/).

Учебный проект курса iOS-разработки Яндекс Практикума ([техническое задание](https://github.com/Yandex-Practicum/travel_schedule)).

## Возможности

- **Поиск маршрута.** Выбор города и вокзала отправления и прибытия с поиском по мере ввода. Направление можно поменять местами одной кнопкой.
- **Список рейсов.** Рейсы на сегодня и завтра, отсортированные по времени отправления. В карточке рейса: перевозчик, дата, время в пути, пересадки.
- **Фильтры.** По времени отправления (утро, день, вечер, ночь) и по наличию пересадок.
- **Перевозчик.** Логотип, название, e-mail и телефон. Почту и номер можно открыть одним нажатием.
- **Сторис.** Полноэкранные истории с прогресс-баром, переключением касанием и закрытием свайпом вниз.
- **Настройки.** Тёмная тема и пользовательское соглашение.
- **Состояния экранов.** Загрузка, пустой результат, «Нет интернета», «Ошибка сервера». Нажатие на экран ошибки повторяет запрос.

## Стек

- SwiftUI, Combine
- MVVM: на каждый экран своя `ViewModel` (`@MainActor`, `ObservableObject`)
- Swift Concurrency: `async/await`, `actor`, `async let`, `TaskGroup`, `withCheckedContinuation`
- [Swift OpenAPI Generator](https://github.com/apple/swift-openapi-generator): клиент генерируется из `openapi.yaml`
- `SWIFT_STRICT_CONCURRENCY = complete`

## Архитектура

```
Trains/
├── App/            # точка входа, таб-бар, глобальные стораджи, зависимости
├── Domain/         # модели (City, Station, Trip, Carrier…) и протоколы репозиториев
├── Data/
│   ├── Networking/ # NetworkClient (actor), middleware, логгер, маппинг ошибок
│   ├── Repositories/
│   ├── Mappers/    # ответы API → доменные модели
│   └── Mock/       # данные для превью
├── Modules/        # экраны: View + ViewModel
├── DesignSystem/   # цвета, шрифты, отступы, общие компоненты
├── Resources/      # строки, ссылки
└── yaml/           # OpenAPI-спецификация
```

**Как устроены данные:**

- `NetworkClient` — `actor` с асинхронными методами для каждого сервиса API.
- Репозитории превращают ответы API в доменные модели:
  - `RemoteCityRepository` загружает справочник станций (~30 МБ) один раз и кэширует его. Если город запрашивают сразу несколько экранов, повторной загрузки не будет. Страны справочника обрабатываются параллельно через `TaskGroup`.
  - `RemoteTripRepository` параллельно запрашивает рейсы на сегодня и завтра через `async let`.
- `ViewModel` запускает загрузку из модификатора `.task`, поэтому запрос отменяется, когда экран закрывается.
- Ошибки сводятся к двум состояниям, «Нет интернета» и «Ошибка сервера». Чтобы различить их, приложение проверяет сеть через `NWPathMonitor`, обёрнутый в `withCheckedContinuation`.

## Логирование сети

В Debug-сборке каждый запрос и ответ выводится в консоль Xcode отдельным блоком через `os.Logger` (категория `Network`):

```
┌────────────────────────────────────────────────────────────
│ → REQUEST #2 · getSchedualBetweenStations
├────────────────────────────────────────────────────────────
│ GET https://api.rasp.yandex.net/v3.0/search/
│   from        s2006004
│   to          s9602494
│   date        2026-10-06
└────────────────────────────────────────────────────────────
┌────────────────────────────────────────────────────────────
│ ← RESPONSE #2 · getSchedualBetweenStations · 200 OK · 556 ms · 47 kB
├────────────────────────────────────────────────────────────
│ {
│   "segments": [
│ …
└────────────────────────────────────────────────────────────
```

- JSON выводится с отступами, даже если ответ обрезан.
- Тело ответа не буферизуется целиком: в лог копируется только его начало.
- API-ключ в лог не попадает.
- В Release-сборке логгер не подключается.

## Требования

- Xcode 26+
- iOS 18.0+
- Только портретная ориентация

## Запуск

1. Клонируйте репозиторий и откройте `Trains.xcodeproj`.
2. Дождитесь, пока Xcode подтянет Swift-пакеты.
3. Соберите и запустите проект (⌘R). Клиент API сгенерируется при сборке.

API-ключ задаётся в `Data/Networking/APIConfiguration.swift`. Получить свой ключ можно в [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/).
